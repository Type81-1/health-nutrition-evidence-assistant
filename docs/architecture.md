## 技术选型

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端 | Vanilla JS + CSS | 零框架，系统字体栈 (PingFang SC / Microsoft YaHei) |
| 后端 | FastAPI + Uvicorn | 异步 Python，SSE 流式支持 |
| 语义检索 | ChromaDB | 本地持久化向量库 |
| 关键词检索 | BM25 (自研) | 中英混合分词，零依赖 |
| 融合排序 | RRF (k=60) | Reciprocal Rank Fusion |
| LLM | DeepSeek (OpenAI API) | 查询翻译 + 流式生成 |
| 外部检索 | PubMed E-utilities + Europe PMC REST | 实时文献检索 |
| 日志 | JSONL 本地文件 | 自动轮转 10MB |
| 评测 | RAGAS 8 维自研框架 | LLM-as-Judge + 启发式指标 |
